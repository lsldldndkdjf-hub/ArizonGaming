# أريزون RP - Arizon Gaming

تطبيق أندرويد احترافي لعبة أريزون RP

## المميزات
- ✅ واجهة تحميل موارد (Splash Screen)
- ✅ الشاشة الرئيسية (Home Screen)
- ✅ شاشة الملف الشخصي مع تغيير الصورة (Profile Screen)
- ✅ شاشة الإعدادات (Settings Screen)
- ✅ تصميم احترافي وجميل
- ✅ دعم اللغة العربية كاملة

## المتطلبات
- Android Studio 2022.1+
- Android SDK 24+
- Kotlin 1.9.0+

## التثبيت
```bash
git clone https://github.com/lsldldndkdjf-hub/ArizonGaming.git
cd ArizonGaming
```

## البناء
```bash
./gradlew build
./gradlew assembleRelease
```
